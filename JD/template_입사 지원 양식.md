# 기업 자체 양식에서 자주 나오는 칸

## 포트폴리오

파일 또는 링크 첨부 가능

## 컴퓨터 활용 능력

```
- 활용 구분: OA, 언어, 그래픽, 공학용, 기타 중 1
- 프로그램명
- 활용 수준: 입문, 초급, 중급, 고급, 특급
- 사용 기간: year 단위로 작성
```

## 수상 경력

```
- 상훈명
- 수여 기관
- 발급일
- 상세 내용 (수상내역을 상세히 입력해주세요.)
```

## 학내외활동

```
- 활동 구분: 동아리활동, 학회, 온라인 커뮤니티, 팀 프로젝트, 재능기부 활동, 기타사회활동, 봉사활동, 교육사항
- 기관 및 조직명
- 활동 기간 (시작 일자부터 종료 일자까지)
- 역할 (지위 또는 역할)
- 상세 내용 (활동 내용을 상세히 입력해주세요.)
```

## 교육 이수 사항

```
- 교육명 (교육 과정명)
- 교육기관명 (교육 기관)
- 이수기간 (시작 일자부터 종료 일자까지)
- 교육시간 (hour 단위로 숫자만 입력)
- 교육과정 (교육 과정 주요 내용을 상세히 입력해주세요.)
```

## 프로젝트

- 본인이 참여한 주요 프로젝트 사항에 대해 간략히 기입해 주시기 바랍니다.
- 발주처에는 프로젝트 의뢰 또는 발단 주체를 적어주시기 바랍니다. (교내 프로젝트인 경우 학교명)

```
- 프로젝트명
- 발주처
- 근무처
- 프로젝트 기간: 시작일 ~ 종료일
- 프로젝트 내용(200자 이내)
- 기여도(%)
- 참여 역할
```

# 사람인 이력서 양식

## 인적사항

- 기본 신상 정보, 사진 (회원 정보 기반 자동 입력됨)
- 학력 (회원 정보 기반 자동 입력됨)

## 경력

```
- 회사명
- 입사년월/퇴사년월 (or 재직중)
- 직무, 근무부서, 직급/직책
- 담당업무
    담당업무를 입력해주세요.
    - 진행한 업무를 다 적기 보다는 경력사항 별로 중요한 내용만 엄선해서 작성하는 것이 중요합니다!
    - 담당한 업무 내용을 요약해서 작성해보세요!
    - 경력별 프로젝트 내용을 적을 경우, 역할/팀구성/기여도/성과를 기준으로 요약해서 작성해보세요!
- 선택사항
    - 연봉
    - 근무지역
    - 퇴사 사유
```

## 스킬

- 툴/직무역량/소프트스킬 입력 가능
- 웬만한 건 다 있으니 자유롭게 작성
- 별다른 갯수 제한 없음

## 경험/활동/교육

```
- 활동구분 선택: 교내활동, 인턴, 자원봉사, 동아리, 아르바이트, 사회활동, 수행과제, 해외연수, 교육이수내역 중 1
- 기관/장소명
- 시작년월/종료년월
- 활동 내용 (분량 제한 없음)
```

## 자격/어학/수상

- 자격증

```
- 자격증명
- 발행처/기관
- 합격구분: 1차합격, 2차합격, 필기합격, 실기합격, 최종합격
- 취득년월
```

- 어학

```
- 언어
- 어학시험명
- 취득년월
- 급수/점수
- 취득여부
```

- 수상내역/공모전

```
- 수상/공모전명
- 수상/공모년월
- 수여/주최기관
```
