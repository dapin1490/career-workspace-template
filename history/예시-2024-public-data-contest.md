# (예시) 공공데이터 분석 공모전: 지역별 공공자전거 수요 분석

> 이 파일은 가상 인물의 예시입니다. 형식과 라벨 쓰는 법을 확인한 뒤 지우십시오.
> 이 파일은 사용자가 직접 썼으므로 라벨이 없습니다.

- 공공데이터 분석 공모전: 지역별 공공자전거 수요 분석 (2024.09.02 - 2024.10.31)
    - 배경 및 목표 (Situation & Task)
        - 지자체 주최 공공데이터 활용 공모전 (분석 부문). 대여소별 대여량과 날씨, 유동인구 데이터를 엮어 신규 대여소 위치를 제안하는 과제.
    - 역할 및 행동 (Action)
        - 2인 팀에서 데이터 수집과 시각화 담당. 공공데이터 포털 API로 1년치 대여 이력을 받아 정리하고, 지도 시각화를 만듦.
    - 어려움 및 해결
        - 대여소 ID 체계가 중간에 바뀌어 같은 대여소가 두 개로 잡힘. → 좌표와 이름으로 매칭표를 만들어 합침.
    - AI 활용
        - 사용하지 않음 (당시 AI 도구를 쓰지 않았음).
    - 기여도 구분: 2인 팀. 본인: 수집, 정제, 시각화. 팀원: 회귀 모델, 보고서 본문.
    - 결과 및 성과 (Result)
        - 본선 진출, 수상은 못함.
    - 한계 / 받은 피드백
        - 제안한 위치의 근거가 상관관계뿐이라는 심사평.
    - 자기소개서 활용 시 주의사항
        - 2년이 지나면 단독 소재로 쓰지 않음. 캡스톤의 데이터 전처리 경험과 이어서 "데이터 정제 경험이 이어진다"는 근거로만 씀 (`AGENTS.md` 행동 규칙 2번).
        - 회귀 모델은 팀원 담당.
    - 자료: 제출 보고서(로컬 보관), 시각화 노트북 GitHub 링크
