# career-workspace-template

AI 에이전트와 함께 취업 준비를 하는 작업 공간 템플릿입니다. 이력 원본, 채용 공고 폴더, 면접 기록, 에이전트 규칙(`AGENTS.md`)을 갖춘 폴더 구조와 예시를 담았습니다. 내 정보를 채우고 첫 프롬프트를 보내면 바로 시작할 수 있습니다.

> 이 README와 `GUIDE.md`는 AI 에이전트(Claude Code)와 함께 작성했습니다.

## 무엇을 해결하나

- 회사마다 자소서를 새로 쓰다 같은 프로젝트를 다르게 적는 문제 → 이력 원본을 한 곳에 두고 거기서 파생
- AI가 사실을 부풀리거나 원본을 마음대로 고치는 문제 → 에이전트 규칙, AI 작성 라벨, 승인 절차
- 지원서를 저장만 하고 최종 제출을 누르지 않는 문제 → 제출 증빙 규칙과 자동 검사(선택)

## 포함된 것

```
career-workspace-template/
├── README.md                ← 이 문서 (빠른 시작)
├── GUIDE.md                 ← 운영 가이드 (원칙, 시작 순서, 선택 기능, 경험담)
├── LICENSE                  ← MIT
├── AGENTS.md                ← 에이전트 행동 규칙
├── full-resume.md           ← 이력 원본의 진입점 (프로필, 이력 색인 표)
├── interview-records.md     ← 면접 기록
├── personal-information.example.md ← 개인정보 파일 형식 (실제 파일은 gitignore)
├── history/                 ← 이력 항목 파일 (작성 규칙, 빈 템플릿, 예시)
├── JD/                      ← 채용 공고 (관리 규칙, 공고 템플릿, 지원 양식 칸 모음, 예시 공고)
├── Artifacts/               ← 에이전트 산출물 (분류 폴더, 관리 규칙)
├── scripts/, .githooks/     ← (선택, Windows 전용) 제출 증빙 자동 검사
├── .claude/settings.json    ← (선택) Claude Code 훅과 제출본 폴더 보호
└── .obsidian/, JD 목록.base  ← (선택) Obsidian 설정과 공고 목록 표
```

## 빠른 시작

1. **저장소 만들기**: "Use this template"로 새 저장소를 만듭니다. 개인 이력이 들어가므로 반드시 **Private**으로 만드십시오. 내려받아 로컬에서만 써도 됩니다.
2. **예시 둘러보기**: `history/예시-...md`와 `JD/예시회사 데이터 분석가/`를 열어 채워진 모습을 봅니다. 라벨과 리스크 메모를 어떻게 쓰는지 보여 줍니다.
3. **에이전트 열기**: 이 폴더에서 AI 코딩 에이전트(Claude Code, Codex 등)를 엽니다. 에이전트는 `AGENTS.md`를 읽고 그 규칙대로 일합니다.
4. **첫 프롬프트 보내기**: 아래 프롬프트를 복사해 보냅니다.
5. **안 쓰는 기능 지우기**: Windows가 아니거나 Obsidian을 쓰지 않는다면 `GUIDE.md` 5절을 보고 지웁니다.

## 첫 프롬프트

빈 문서를 혼자 채우는 대신, 에이전트가 질문하고 내가 답하는 방식으로 시작합니다.

**1. 예시 정리와 프로필 인터뷰**

```
AGENTS.md와 GUIDE.md를 읽어 줘. 그다음 예시 파일(이름에 '예시'가 들어간 파일과 폴더, full-resume.md 색인 표의 예시 행)을 지워도 되는지 목록으로 보여 주고, 내가 승인하면 지워 줘.
그 뒤에 full-resume.md의 프로필을 채우도록 나에게 질문해 줘. 한 번에 두세 개씩만 묻고, 스킬 레벨은 입문, 초급, 중급, 고급, 특급 중에서 같이 정하자.
```

**2. 이력 항목 인터뷰** (프로젝트마다 반복)

```
history/README.md의 규칙에 따라 내 프로젝트 경험 하나를 이력 항목으로 정리하고 싶어. history/_template.md의 칸 순서대로 나에게 질문해 줘.
내가 답한 내용만 쓰고, 모르는 칸은 비워 둬. 수치에는 근거가 있는지 물어봐 줘.
초안은 Artifacts/maintenance/에 만들고, 내가 확인하면 history/로 옮기고 full-resume.md 색인 표에 한 줄 추가해 줘.
```

**3. 공고 등록**

```
아래 공고를 JD/template.md 형식으로 JD/에 등록해 줘. 공고 원문은 다음과 같아.
(공고 링크나 원문 붙여 넣기)
```

**4. 자소서 초안**

```
JD/(공고 폴더)의 자소서 문항 초안을 써 줘. full-resume.md, history/, interview-records.md만 근거로 쓰고, 어느 파일의 어떤 사실을 썼는지 밝혀 줘.
```

## 더 읽을 것

- 이력 작성 규칙과 AI 라벨: `history/README.md`
- 공고 폴더 관리: `JD/README.md`
- 제출 증빙 자동 검사 설치: `scripts/README.md`
